# 📊 Student Performance Analysis

## 🎯 Objective
To analyze factors affecting student exam performance and build a predictive model.

## 📊 Features Used
- Hours Studied
- Attendance
- Previous Scores

## 🤖 Model Used
- Linear Regression

## 📈 Key Insights
- Study hours and attendance have the highest impact on exam scores
- Previous scores have a smaller influence

## 🛠 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 🚀 Result
Successfully built a model to predict student exam scores and analyzed key influencing factors.
